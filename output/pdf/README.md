# Shareable submission PDFs

- [Final project report](CN_Project_Final_Report.pdf): the supplied
  `CN_PROJECT_REPORT.pdf` export, copied without changing its bytes; 15 A4 pages.
- [Viva command menu](CN_Project_Viva_Command_Menu.pdf): 20 pages of per-person
  demonstration commands, expected results, explanations and restoration steps.

Editable report sources are [LaTeX](../../docs/final-project-report.tex) and
[Markdown](../../docs/final-project-report.md). The submitted PDF is the
user-supplied Overleaf export; future edits should update the source and replace
the PDF with the newly compiled export together. The LaTeX is a standalone A4
article based on the supplied style, with no separate figure files required.

The [artifact manifest](submission-manifest.json) records the current hashes.
Raw test evidence under `evidence/` is preserved separately. Earlier manifests
describe their original snapshots and are not rewritten when documentation evolves.
